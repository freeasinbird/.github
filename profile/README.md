# Free as in Bird

We make software and set it free.

Everything we build depends on work that came before it — other people's ideas, tools, and generosity. We carry that forward: whatever we make is there to fuel whoever comes next.

Our principle is that the knowledge embedded in source code belongs to everyone, so we match each project's license to the type of work: [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) for knowledge artifacts, [LGPL-3.0](https://www.gnu.org/licenses/lgpl-3.0.html) for libraries, and [GPL-3.0](https://www.gnu.org/licenses/gpl-3.0.html) or [AGPL-3.0](https://www.gnu.org/licenses/agpl-3.0.html) for standalone tools. That way the knowledge stays free, but what you build with it is yours.
